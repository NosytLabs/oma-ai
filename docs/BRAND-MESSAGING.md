## What OMA IS

- **AI inference gateway** - Routes requests to AI providers via OpenAI-compatible API
- **Private access layer** - Zero data retention on prompt content; self-hosted control available
- **Venice-powered backend** - Primary provider with 91+ models, backup via AntSeed
- **Credit-based billing** - Prepay with crypto, earn credits, spend on inference
- **Multi-provider routing** - Circuit breaker pattern for failover; multi-model support ready
- **Self-hosted option** - Full control via Coolify deployment; no vendor lock-in
- **Crypto-native payments** - x402 support, cross-chain deposits via HoudiniSwap (20+ chains)
- **Wallet-based auth** - SIWE sign-in, instant API key generation

## What OMA is NOT

| Avoid Term | Use Instead | Reason |
|------------|-------------|--------|
| "No KYC" | "Low-friction signup" | Avoids regulatory connotations; emphasizes ease |
| "Anonymous inference" | "Private inference" | Accurate privacy claim without implying untraceability |
| "Untraceable" | "Privacy-focused" | Honest about privacy without absolute claims |
| "Dark" / "Underground" | "Self-hosted" / "Crypto-native" | Professional positioning for builders |
| "Cheap tokens" | "Cost-effective inference" | Value proposition beyond just price |
| "Just another proxy" | "Full inference gateway" | Emphasizes feature completeness |

**Key Clarification:** OMA is NOT designed for illicit use. It is a professional tool for developers who value privacy, control, and crypto-native payments.

## Words to AVOID

| Word/Phrase | Why | Alternative |
|-------------|-----|-------------|
| No KYC | Regulatory red flag; implies circumventing compliance | "Low-friction signup" / "Wallet-based auth" |
| Anonymous | Cannot guarantee; implies untraceable | "Private" / "Privacy-first" |
| Untraceable | Legal exposure; absolute claim | "No data retention" / "Self-hosted option" |
| Dark web / Underground | Association with illicit use | "Self-hosted" / "Crypto-native" |
| Illicit / Illegal | Distance from any negative use cases | N/A - simply don't reference |
| Bypass | Implies circumventing controls | "Skip" / "Avoid friction" |
| Cheap | Devalues offering; attracts wrong audience | "Cost-effective" / "Competitive pricing" |
