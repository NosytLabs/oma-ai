# File Upload — Reusable Component

## Requirements
- Reusable file upload / image upload component
- Drag-and-drop support
- Click-to-browse fallback
- Image preview before upload
- Used primarily for image-to-video upload in video generation
- Optimize images to reasonable size before upload
- Convert to base64 data URL for preview and URL for API call

## File Structure
- `app/src/components/ui/FileUpload.tsx` — Reusable upload component
