# OMA marketing kit

All files here are regenerated by `pnpm --filter app brand:generate` from the same geometry as the live logo. Do not edit them independently.

- `oma-icon-promo.jpg`: app mark on a dark canvas.
- `oma-lockup-horizontal.png` and `.jpg`: horizontal OMA lockup.
- `oma-brand-card.png`: high-resolution social card.

Canonical SVGs, app icons and provider assets live in the parent directory. The shared symbol geometry is `app/src/lib/brand-mark.json`.
