# Provider logo tiles

Local fallback SVGs used by `ModelLogo` when SimpleIcons CDN is missing a
slug or returns 404. Prefer these over remote CDNs for offline reliability
and zero console noise.

| File | Used for |
|------|----------|
| `openai.svg` | GPT / OpenAI-family ids |
| `anthropic.svg` | Claude / Anthropic |
| `google.svg` | Gemini |
| `meta.svg` | Llama |
| `deepseek.svg` | DeepSeek |
| `mistral.svg` | Mistral |
| `xai.svg` | Grok / xAI |
| `moonshot.svg` | Kimi / Moonshot |
| `alibaba.svg` | Qwen |
| `minimax.svg` | MiniMax |
| `xiaomi.svg` | MiMo |
| `zai.svg` | GLM / Zhipu |
| `mercury.svg` | Mercury / Inception |
| `venice.svg` | Venice-routed generic |

Keep tiles 24×24, rounded `rx=6`, high-contrast initials.
