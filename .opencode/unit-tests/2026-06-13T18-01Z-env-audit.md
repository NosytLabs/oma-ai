## 5 Actionable Gaps (Ranked by Impact)

1. **HIGH** — `ENCRYPTION_KEY` (config.ts:56) lacks production length/uniqueness guard. Dev default `dev-secret-change-me-in-prod-32ch` would be silently used in prod → AES-256-GCM TOTP-secret encryption compromised. **Fix snippet in report §Gap-1.**
2. **MEDIUM** — `TRUSTED_PROXY_IPS` read via raw `process.env` in `middleware/rate-limit/utils.ts:4` bypasses the zod schema (which is at `config.ts:141`). **Fix: import `config` and use `config.TRUSTED_PROXY_IPS`.**
3. **MEDIUM** — `LOG_LEVEL` read via raw `process.env` in `lib/logger.ts:6` bypasses zod; invalid values crash pino. **Fix: add to schema as `z.enum([...]).optional()` and read via `config.LOG_LEVEL`.**
4. **MEDIUM** — 4 `X402_*` env vars documented in `.env.example:163-167` but NOT wired in `x402/crosschain.ts` (test fixtures only). **Fix: wire or remove from .env.example.**
5. **LOW** — 5 dead env vars in config.ts schema (`GROQ_API_KEY`, `CEREBRAS_API_KEY`, `BEDROCK_*` ×3). **Fix: delete from schema.**
