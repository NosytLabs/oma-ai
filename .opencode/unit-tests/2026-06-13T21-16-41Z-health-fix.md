## Diagnosis (recap)
- **Bug**: App's `/api/health` proxied to backend `http://localhost:3001/health`.
  When backend is offline, proxy returns 503 → frontend shows "Reconnecting…"
  indicator on every public page, even pages that don't need the backend.
- **Fix**: Decoupled. `/api/health` is now a static `{ status: 'ok', service, timestamp }`
  200 response. Backend reachability concerns move to the actual API call
  sites (chat, models, balance) where the user has a real reason to care.
- **Scope**: 1 file, 36 → 30 lines (+13 comment lines for intent, -13 logic
  lines for the proxy).
